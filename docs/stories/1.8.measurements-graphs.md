# Story 1.8: Measurements Graphs View

## Status: Completed

## Story
**As a** user,
**I want** to visualize my body measurements evolution over time with graphs,
**so that** I can better understand my physical progress and trends.

## Acceptance Criteria
1. Page `/profile/measurements/graphs` accessible depuis l'icône graphique dans la page mensurations
2. Sélecteur de mesure (poids, tour de taille, biceps, etc.) avec dropdown ou tabs
3. Graphique linéaire affichant l'évolution de la mesure sélectionnée dans le temps
4. Période de temps configurable (1 mois, 3 mois, 6 mois, 1 an, tout)
5. Affichage des points de données avec date et valeur au survol/tap
6. Pour les mesures bilatérales (biceps, cuisses, etc.), afficher les deux courbes (G/D) superposées
7. Indicateurs de tendance : progression globale (%, valeur absolue)
8. Design responsive et cohérent avec le thème sombre de l'application

## Dev Notes

### Librairie recommandée : Recharts
Recharts est recommandé car :
- Basé sur React, composants déclaratifs
- Bonne documentation
- Responsive par défaut
- Facile à thématiser

```bash
npm install recharts
```

### Structure des données pour le graphique
```typescript
interface ChartDataPoint {
  date: string;        // Format YYYY-MM-DD
  value: number;       // Valeur de la mesure
  valueLeft?: number;  // Pour mesures bilatérales
  valueRight?: number; // Pour mesures bilatérales
}

// Exemple pour poids
const weightData: ChartDataPoint[] = [
  { date: "2024-04-28", value: 75.0 },
  { date: "2024-06-16", value: 76.0 },
];

// Exemple pour biceps (bilatéral)
const bicepsData: ChartDataPoint[] = [
  { date: "2024-04-28", valueLeft: 31.0, valueRight: 32.5 },
  { date: "2024-06-16", valueLeft: 31.5, valueRight: 32.5 },
];
```
