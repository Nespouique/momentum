# Story 2.11: Ad-hoc Workout Sessions

## Status: Completed

## Story

**As a** user arriving at the gym without a workout plan,
**I want** to start an ad-hoc session from one exercise and choose what comes next,
**so that** I can train freely without creating a reusable workout first.

## Acceptance Criteria

1. The workouts page offers an “À la volée” entry when no session is active.
2. The user selects a first exercise and starts immediately.
3. Targets reuse the latest completed performance when available, otherwise three sets of ten are created.
4. After the last set of each exercise, the user can add another exercise or finish the session.
5. Adding an exercise resumes the standard exercise flow without losing recorded results.
6. The same exercise cannot be added twice in the MVP.
7. Ad-hoc sessions appear in active state, history, calendar, details and exercise statistics.
8. Ad-hoc sessions are stored without a workout and labelled “À la volée”.
9. Template progression acceptance and AI coaching are not offered because no workout template exists.
10. Reloading after an exercise restores the add-or-finish decision.

## Implementation Notes

- `WorkoutSession.type` distinguishes `planned` and `ad_hoc`.
- `WorkoutSession.workoutId` is nullable; consumers must handle a null workout.
- Dynamic `SessionExercise` rows deliberately have no `workoutItem` references.
