# Story 2.12: Extra Set During Session ("1 more")

## Status: Completed

## Story

**As a** user finishing the last set of an exercise,
**I want** to add one more set without leaving the exercise,
**so that** I can keep going when I still have energy, without having planned that set in advance.

## Acceptance Criteria

1. On the rest screen after the last set of a standard exercise, a button “Ajouter une série (1 more)” is shown right after the “SÉRIE N TERMINÉE” result block.
2. The same button is shown on the transition screen (end of exercise, before the next exercise), so the choice is not lost when another exercise follows.
3. The button is available in planned and ad-hoc sessions. It is not offered for supersets.
4. Clicking it stops the rest timer, saves any result edited during the rest, appends one set to the same exercise and resumes the exercise screen on that new set.
5. The new set repeats what was just done: its target reps and weight come from the last recorded result of the exercise, otherwise from its last target.
6. Recorded results of previous sets are never lost, and the workout template is never modified.
7. An exercise cannot exceed 20 sets; skipped or substituted exercises cannot be extended.
8. If adding the set fails, the rest timer resumes where it was and an error toast is shown.
9. Reloading the session after adding a set keeps the extra set and its position in the flow.

## Implementation Notes

- `POST /sessions/:id/exercises/:exerciseId/extra-set` (no body) locks the session row, requires an in-progress session and a non-skipped, non-substituted exercise, and creates the next `setNumber`. It returns 201 `{data:SessionSet}`.
- Errors: 404 `NOT_FOUND`, 400 `SESSION_NOT_ACTIVE`, 409 `CONFLICT` (skipped/substituted exercise or 20-set cap).
- Web: `addExtraSet` action in `stores/session.ts` freezes `restEndAt` while it works so `tick()` cannot trigger `skipRest`. The result-flush logic of `skipRest` was extracted into `flushRestResults`, shared by both actions.
- Supersets are out of scope: adding a set there means adding a round to every member exercise.
- The button is only offered at the end of an exercise, not between two sets.

- `npm run lint`, web TypeScript check and API build pass.
