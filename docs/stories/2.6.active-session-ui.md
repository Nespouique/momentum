# Story 2.6: Active Workout Session - UI

## Status: Completed

## Story
**As a** user,
**I want** an optimized interface during my workout with historical comparison,
**so that** I can track my sets efficiently, compare to my previous performance, and manage my exercises flexibly.

## Acceptance Criteria

### Architecture Composants Réutilisables (CRITIQUE)
1. **Composants atomiques** conçus pour être réutilisés dans les différents écrans :
   - `TimerBlock` : Timer + boutons ±30s + progress bar + bouton skip
   - `ResultInput` : Objectif affiché + steppers reps/kg pour saisir résultat
   - `NextPreview` : Preview de la prochaine série ou exercice avec historique
   - `ExerciseOptionsBar` : Barre Sauter / Reporter / Substituer
   - `SupersetProgress` : Indicateur de tour et progression dans le superset
2. **Pas de duplication de code** entre les écrans exercice standard et superset

### Écran Exercice en cours (lecture seule)
3. Affichage du nom de l'exercice et groupes musculaires
4. Indicateur de série en cours (ex: "Série 2/4" + progress dots ○ ● ○ ○)
5. Bloc comparatif : **Objectif** (reps @ kg) vs **Dernière fois** (reps @ kg) avec tendance 📈📉➡️
6. Indication du temps de repos à venir après la série
7. Bouton large "SÉRIE TERMINÉE" (≥60px) comme unique CTA
8. **Pas de steppers** sur cet écran (lecture seule)

### Écran Repos + Saisie résultat (après validation série)
9. `TimerBlock` en haut : timer countdown + ±30s + progress bar + bouton skip `[ ✓ ]`
10. `ResultInput` : Objectif affiché + steppers pour saisir actualReps/actualWeight
11. `NextPreview` : Preview de la prochaine série avec objectif et historique
12. Countdown audio : bips à 5, 4, 3, 2, 1 secondes, double bip à 0
13. Animation visuelle (pulse/couleur) dans les 5 dernières secondes

### Écran Transition exercice (fin d'exercice → prochain)
14. Titre "EXERCICE TERMINÉ" + nom de l'exercice complété
15. `TimerBlock` identique à l'écran repos
16. `ResultInput` pour la dernière série de l'exercice terminé
17. `NextPreview` : Prochain exercice avec nom, nb séries, objectif série 1, historique
18. `ExerciseOptionsBar` : **Uniquement ici** - Sauter / Reporter / Substituer

### Options exercice (uniquement sur écran transition)
19. **Sauter** : Marque l'exercice comme "skipped", passe au suivant
20. **Reporter** : Ouvre un écran de réordonnancement avec drag & drop (@dnd-kit)
21. **Substituer** : Ouvre ExerciseSelector existant filtré par groupe musculaire
22. Substitution temporaire pour la session uniquement (ne modifie pas le workout)

### Supersets - Exercice en cours
23. `SupersetProgress` en haut : "SUPERSET · Tour X/Y" + liste exercices (✓ ● ○)
24. Même structure que l'écran exercice standard (lecture seule)
25. "SÉRIE TERMINÉE" → passe à l'exercice suivant du superset **sans timer**

### Supersets - Repos entre tours
26. `TimerBlock` identique (même composant)
27. **Plusieurs `ResultInput`** : Un bloc par exercice du tour (3 exercices = 3 blocs)
28. `NextPreview` : Aperçu du prochain tour

### Supersets - Transition (fin du superset complet)
29. Titre "SUPERSET TERMINÉ · X tours"
30. `TimerBlock` + **plusieurs `ResultInput`** (dernier tour)
31. `NextPreview` + `ExerciseOptionsBar` (même composants que transition standard)

### Flow Reporter (drag & drop)
32. Écran plein avec liste des exercices restants
33. Poignées drag & drop `≡` sur chaque exercice (même UX que workout builder)
34. Utilise @dnd-kit (composant existant)
35. Bouton "Confirmer" pour valider le nouvel ordre

### Flow Substituer
36. Réutilise `ExerciseSelector` existant du workout builder
37. Groupe musculaire de l'exercice original pré-sélectionné
38. Au tap → substitution immédiate, retour à l'écran transition

### Écrans globaux
39. Page `/session/:id` en mode full-screen (navigation principale masquée)
40. Header minimal avec titre workout et bouton abandon `✕`
41. Bouton "Abandon" avec confirmation (dialog)
42. Wake Lock API pour empêcher la mise en veille
43. Session Summary à la fin avec stats et possibilité d'ajouter des notes

## Dev Notes

### IMPORTANT : Architecture Composants

**Objectif : ZÉRO duplication de code entre exercices standards et supersets.**

Tous les écrans doivent être composés à partir des mêmes blocs :

```tsx
// Écran Repos (exercice standard)
<RestScreen>
  <TimerBlock duration={90} onComplete={...} />
  <ResultInput exercise={current} />
  <NextPreview type="set" data={nextSet} />
</RestScreen>

// Écran Repos (superset - seule différence : plusieurs ResultInput)
<SupersetRestScreen>
  <TimerBlock duration={90} onComplete={...} />
  {supersetExercises.map(ex => (
    <ResultInput key={ex.id} exercise={ex} />
  ))}
  <NextPreview type="set" data={nextRound} />
</SupersetRestScreen>

// Écran Transition (exercice standard)
<TransitionScreen>
  <TimerBlock duration={120} onComplete={...} />
  <ResultInput exercise={lastSet} />
  <NextPreview type="exercise" data={nextExercise} />
  <ExerciseOptionsBar onSkip={...} onPostpone={...} onSubstitute={...} />
</TransitionScreen>

// Écran Transition (superset - MÊME structure, juste titre et ResultInput multiples)
<SupersetTransitionScreen>
  <TimerBlock duration={120} onComplete={...} />
  {lastRoundExercises.map(ex => (
    <ResultInput key={ex.id} exercise={ex} />
  ))}
  <NextPreview type="exercise" data={nextExercise} />
  <ExerciseOptionsBar onSkip={...} onPostpone={...} onSubstitute={...} />
</SupersetTransitionScreen>
```

### Web Audio API

```typescript
// Créer l'AudioContext après première interaction utilisateur
let audioContext: AudioContext | null = null;

const initAudio = () => {
  if (!audioContext) {
    audioContext = new AudioContext();
  }
};

const playBeep = (frequency: number, duration: number) => {
  if (!audioContext) return;
  const oscillator = audioContext.createOscillator();
  oscillator.type = 'sine';
  oscillator.frequency.value = frequency;
  oscillator.connect(audioContext.destination);
  oscillator.start();
  oscillator.stop(audioContext.currentTime + duration / 1000);
};

// Countdown
const playCountdownBeep = (secondsRemaining: number) => {
  if (secondsRemaining > 0 && secondsRemaining <= 5) {
    playBeep(440, 100); // Bip court
  } else if (secondsRemaining === 0) {
    playBeep(880, 300); // Bip long
    setTimeout(() => playBeep(880, 300), 350); // Double bip
  }
};

// Appeler initAudio() au clic sur "SÉRIE TERMINÉE" la première fois
```

### Zustand Session Store

```typescript
interface SessionState {
  // État
  session: WorkoutSession | null;
  lastSession: WorkoutSession | null; // Pour comparaison historique
  currentExerciseIndex: number;
  currentSetIndex: number;
  isResting: boolean;
  restTimeRemaining: number;

  // Pour supersets
  isInSuperset: boolean;
  supersetRound: number;
  supersetExerciseIndex: number;

  // Résultats en cours de saisie
  pendingResults: Map<string, { reps: number; weight: number }>;

  // Actions
  startSession: (session: WorkoutSession, lastSession?: WorkoutSession) => void;
  completeSet: (exerciseId: string, setNumber: number, result: { reps: number; weight: number }) => void;
  completeExercise: () => void;
  skipExercise: () => void;
  postponeExercise: () => void;
  substituteExercise: (newExerciseId: string) => void;
  reorderExercises: (exerciseIds: string[]) => void;
  skipRest: () => void;
  adjustRestTime: (delta: number) => void;
  abandonSession: () => void;
  completeSession: (notes?: string) => void;

  // Helpers
  getCurrentExercise: () => SessionExercise | null;
  getNextExercise: () => SessionExercise | null;
  getCurrentSet: () => SessionSet | null;
  getLastSessionSet: (exerciseId: string, setNumber: number) => SessionSet | null;
}
```
