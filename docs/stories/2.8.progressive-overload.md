# Story 2.8: Progressive Overload System

## Status: Completed

## Story
**As a** user,
**I want** the app to analyze my completed workout and suggest weight or rep increases,
**so that** I continuously progress without having to manually track patterns.

## Acceptance Criteria

### Affichage sur la page de fin de séance
1. Sur la page de résumé de séance (Session Summary), sous chaque carte d'exercice, afficher une zone de suggestion de progression si applicable
2. La suggestion s'affiche uniquement si l'algorithme détecte qu'une progression est recommandée
3. L'utilisateur peut Accepter ou Ignorer chaque suggestion individuellement

### Algorithme d'évaluation de progression
4. Analyser la performance de la séance actuelle pour chaque exercice :
   - Comparer reps réelles vs reps cibles
   - Comparer poids réels vs poids cibles
5. Analyser l'historique des 3-4 dernières sessions pour détecter une stabilisation (mêmes valeurs ±5%)
6. Critères de déclenchement d'une suggestion :
   - **Target atteint ou dépassé** : Si l'utilisateur a atteint ou dépassé les reps cibles sur toutes les séries → suggérer +poids
   - **Stabilisation** : Si performance stable sur 3+ sessions → suggérer progression
   - **Sous-performance** : Si l'utilisateur n'atteint pas les cibles → ne pas suggérer (ou suggérer de maintenir)

### Logique de suggestion
7. Règles de progression :
   - **Augmentation poids** : +2.5kg (isolation/petit muscle) ou +5kg (compound/grand muscle)
   - **Augmentation reps** : +1-2 reps si le poids ne peut pas augmenter facilement
8. Générer un message explicatif lisible ("Vous avez dépassé vos cibles sur toutes les séries. Prêt pour 62.5kg ?")

### Application des suggestions
9. Si accepté : Mettre à jour les `targetWeight` et/ou `targetReps` dans le **workout template** (`WorkoutSet`)
10. Les futures séances utiliseront automatiquement les nouvelles cibles

### Cooldown et limitations
11. Ne pas re-suggérer le même type de progression si ignoré récemment (cooldown de 2-3 sessions)
12. Stocker l'historique des suggestions dans un nouveau modèle `ProgressionSuggestion`

### Historique des suggestions (optionnel)
13. Pouvoir consulter l'historique des suggestions acceptées/ignorées dans les stats de l'exercice

### Algorithme d'évaluation (progression.service.ts)

```typescript
interface ProgressionAnalysis {
  shouldSuggest: boolean;
  suggestionType: 'increase_weight' | 'increase_reps' | null;
  currentValue: number;
  suggestedValue: number;
  reason: string;
}

async function evaluateExercise(
  userId: string,
  exerciseId: string,
  currentSessionSets: SessionSet[]
): Promise<ProgressionAnalysis> {

  // 1. Calculer performance de la session actuelle
  const avgActualReps = average(currentSessionSets.map(s => s.actualReps));
  const avgActualWeight = average(currentSessionSets.map(s => s.actualWeight));
  const avgTargetReps = average(currentSessionSets.map(s => s.targetReps));
  const avgTargetWeight = average(currentSessionSets.map(s => s.targetWeight));

  // 2. Vérifier si cibles atteintes/dépassées sur TOUTES les séries
  const allSetsMetTarget = currentSessionSets.every(s =>
    s.actualReps >= s.targetReps &&
    (s.targetWeight === null || s.actualWeight >= s.targetWeight)
  );

  if (!allSetsMetTarget) {
    return { shouldSuggest: false, ... };
  }

  // 3. Vérifier cooldown (pas de suggestion récente ignorée)
  const recentDismissed = await checkRecentDismissed(userId, exerciseId, 3);
  if (recentDismissed) {
    return { shouldSuggest: false, ... };
  }

  // 4. Récupérer historique pour détecter stabilisation
  const history = await getExerciseHistory(userId, exerciseId, 4);
  const isStable = checkStability(history, 0.05); // ±5%

  // 5. Déterminer type de suggestion
  const exercise = await prisma.exercise.findUnique({ where: { id: exerciseId }});
  const isCompound = isCompoundExercise(exercise.muscleGroups);
  const weightIncrement = isCompound ? 5 : 2.5;

  // 6. Suggérer augmentation de poids si target reps atteint
  if (avgActualReps >= avgTargetReps && avgTargetWeight) {
    return {
      shouldSuggest: true,
      suggestionType: 'increase_weight',
      currentValue: avgTargetWeight,
      suggestedValue: avgTargetWeight + weightIncrement,
      reason: `Objectifs atteints sur toutes les séries. Prêt pour ${avgTargetWeight + weightIncrement}kg ?`
    };
  }

  // 7. Suggérer augmentation de reps si poids stable
  if (isStable && history.length >= 3) {
    return {
      shouldSuggest: true,
      suggestionType: 'increase_reps',
      currentValue: avgTargetReps,
      suggestedValue: avgTargetReps + 2,
      reason: `Performance stable depuis ${history.length} séances. Essayez ${avgTargetReps + 2} reps !`
    };
  }

  return { shouldSuggest: false, ... };
}

// Identifier si exercice compound (plusieurs grands groupes musculaires)
function isCompoundExercise(muscleGroups: string[]): boolean {
  const majorGroups = ['pectoraux', 'dos', 'quadriceps', 'ischios', 'fessiers'];
  return muscleGroups.filter(g => majorGroups.includes(g)).length >= 1;
}
```
