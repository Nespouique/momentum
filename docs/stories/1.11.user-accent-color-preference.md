# Story 1.11: User Accent Color Preference

## Status: Completed

## Story

**As a** user,
**I want** to choose the application's accent color,
**so that** primary actions and selected controls match my visual preference.

## Acceptance Criteria

1. Profil > Paramètres opens a working settings page.
2. The page exposes a color picker and a valid hexadecimal value.
3. The preference is persisted per user and restored after authentication.
4. Primary controls, focus rings and selected workout controls use the preference.
5. Foreground text automatically remains readable for light and dark colors.
6. The user can reset the preference to the current white default.

## Implementation Notes

- Preference persisted as `User.accentColor`.
- Runtime theme uses `--primary`, `--primary-foreground` and `--ring`.
- Semantic chart, warning and muscle-group colors remain unchanged.
