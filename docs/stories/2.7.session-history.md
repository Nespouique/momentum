# Story 2.7: Session History & Details

## Status: Completed

## Story
**As a** user,
**I want** to view my past workout sessions,
**so that** I can track my training consistency and review my performance.

## Acceptance Criteria

### Point d'entrée historique
1. Icône `History` en haut de l'écran `/workouts` (dans PageHeader actions, comme pour les mensurations)
2. Au clic sur l'icône, une Sheet s'ouvre avec la liste des séances passées (status=completed)

### Liste des sessions (Sheet)
3. Réutilisation du composant `WorkoutCard` avec `variant="history"` :
   - Nom du workout
   - Date de la session (format relatif : Aujourd'hui, Hier, Il y a X jours)
   - Nombre d'exercices **réalisés** (pas prévus) - comptage des SessionExercise avec au moins 1 set complété
   - Groupes musculaires (badges)
   - ❌ Pas de boutons Play et Copy
   - ✅ Bouton Delete pour supprimer une session passée
4. Tri par date décroissante (plus récentes en premier)
5. Scroll dans la Sheet

### Détail session (au clic sur une carte)
6. Navigation vers écran de récap de la session
7. Réutilisation du composant `SessionSummary` adapté pour le mode consultation/édition
8. Header avec : nom du workout, date (non modifiable), durée
9. Liste des exercices réalisés avec leurs sets
10. Possibilité de **modifier les valeurs** (reps, poids) via `ResultInput`
11. Bouton "Enregistrer les modifications" → `PUT` pour sauvegarder
12. **Ne jamais modifier la date de la session**

### Calcul du nombre d'exercices réalisés

```typescript
// Un exercice est "réalisé" s'il a au moins 1 set avec actualReps !== null
const completedExerciseCount = session.exercises.filter(ex =>
  ex.sets.some(set => set.actualReps !== null)
).length;
```

### Date Formatting (déjà existant dans workouts/page.tsx)
```typescript
// Réutiliser formatLastExecutionDate de la page workouts
const formatSessionDate = (dateStr: string): string => {
  const date = new Date(dateStr);
  const now = new Date();
  const diffMs = now.getTime() - date.getTime();
  const diffDays = Math.floor(diffMs / (1000 * 60 * 60 * 24));

  if (diffDays === 0) return "Aujourd'hui";
  if (diffDays === 1) return "Hier";
  if (diffDays < 7) return `Il y a ${diffDays} jours`;
  if (diffDays < 30) {
    const weeks = Math.floor(diffDays / 7);
    return `Il y a ${weeks} semaine${weeks > 1 ? "s" : ""}`;
  }
  return date.toLocaleDateString("fr-FR", { day: "numeric", month: "short" });
};
```
